# التحكم في إضاءة الـ LED عبر خادم الويب باستخدام ESP32

يقوم هذا المشروع بالتحكم في حالة إضاءة الـ LED باستخدام متحكم ESP32، وذلك عن طريق قراءة القيمة (`1` للتشغيل، `0` للإيقاف) من ملف نصي مستضاف على خادم إنترنت خارجي.

## 🛠️ مكونات وتفاصيل المشروع
* **المتحكم:** ESP32
* **استضافة الخادم:** InfinityFree
* **بروتوكول الاتصال:** HTTP GET Request

## 🌐 رابط الخدمة المباشر (Live Endpoint)
يمكنك التحقق من حالة الملف النصي المباشرة على الخادم عبر الرابط التالي:
[http://rayan09.freehosting.dev/status.txt](http://rayan09.freehosting.dev/status.txt)

## 🚀 آلية العمل
1. يتصل متحكم ESP32 بشبكة الواي فاي المحددة.
2. يرسل المتحكم طلب HTTP GET دوري إلى الملف `status.txt` الموجود على السيرفر.
3. يقرأ النص القادم من السيرفر (`1` أو `0`) ويقوم بتحديث حالة منقذ الـ LED بناءً عليه:
   * `1` $\leftarrow$ تشغيل الـ LED (**ON**)
   * `0` $\leftarrow$ إيقاف الـ LED (**OFF**)
